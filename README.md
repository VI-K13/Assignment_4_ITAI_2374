# Robot HAT Hardware Components Documentation

This project documents the main hardware features of the SunFounder Robot HAT and explains how they support robotics applications with Raspberry Pi 5. It covers the motor driver, PWM servo control, ultrasonic sensor connection, ADC inputs, audio support, battery power, I²C/UART/SPI expansion ports, and status indicators.

The project also includes PiDog V2 as an example of how the Robot HAT connects sensors, processing, and servo movement in a real robotic system.
